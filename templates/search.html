What happens when you search

The form above sends your search to this server. The server runs a PostgreSQL full-text query over the site’s published content and returns the results as a page, with JavaScript on or off.

Trovato can also run keyword search in the browser, and it can use a language model to expand a query and summarise the results. This site uses neither. The search page loads no in-browser search, and no AI provider is configured, so nothing you type leaves this server. If that changes, this page will say so and name the provider.

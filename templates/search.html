What happens when you search

With JavaScript on, your browser downloads a small search index that this server builds from the site’s published content. Your browser then matches your words against that index, in the page itself.

With JavaScript off, or before the index has loaded, the form sends your search to this server. The server runs a PostgreSQL full-text query and returns a page of results.

This site uses no AI and no outside service for search, so what you type stays in your browser or on this server. If an AI provider is added, this page will say so and name it.
